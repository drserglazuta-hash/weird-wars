# Final

Build the complete UI and interactive screen flows for "Weird Wars" — a browser card-strategy game set in a living children's sketchbook on a wooden desk.

Scene & Atmosphere:
- Global desk scene: warm wood surface with hand-drawn objects (paint tubes, brushes, glass jar of water, crayons, pencil stubs, dark ink blots/кляксы, and loose scattered NFT cards).
- The central open sketchbook (#FAF7F0 paper) acts as the active canvas for screens.
- Consistent charming child hand-drawn art style (wobbly naive pen/crayon lines, rounded display typography, crayon accents: coral, sunshine, mint, sky, and deep ink navy/weird violet #6C5CE7 accents).

Screens and navigation:
1. Connect / Main Menu: "Connect Keplr" button, tagline "Wake the drawings. Fight the Blot.", transitions to game modes (Campaign, Duel vs Human, Duel vs AI).
2. Campaign Map: Hand-drawn winding treasure map path with level flags that unlock sequentially and open squad setup.
3. Squad Setup: Deck builder with 7 friend card slots + 1 shadow commander slot, level up cards with tokens, card details, and "Start Battle".
4. Battle Field: Grid battlefield inside the sketchbook with player units vs Blot monsters, turn-order speed bar, hand of action cards, and animated Victory/Defeat overlays.
5. Season / Rating: Quarterly leaderboard with rank, rating points, countdown timer, and tier prizes.
6. Duel Modes: Duel vs AI setup and Duel vs Human "waiting for opponent" matchmaking screen.

Include rich art-forward card templates (Friends, Shadows, Multiverse frames) featuring child-drawn creature art.
